# Foundora

Plan. Validate. Launch. A single-page website for Foundora, an AI-powered startup companion for first-time entrepreneurs in the UAE (ENT 241 project, Canadian University Dubai).

It is a static site (`index.html`), ready to deploy on Vercel with no build settings. The link and QR code on the page are generated from whatever address the site is served at.

`vendor/qrcode.js` is [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4 by Kazuhiko Arase, MIT licence.
